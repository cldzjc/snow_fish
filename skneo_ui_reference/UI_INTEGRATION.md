# skneo UI 交付说明

## 交付边界

这是产品界面源代码，不是设计展示台。启动后直接进入首页，没有画板、页面目录、状态控制台或设计说明。

- `src/App.tsx`：页面、共用组件、模拟数据与本地交互。
- `src/index.css`：Tailwind 入口、系统字体与断点。
- React + TypeScript + Tailwind 用于表达视觉与交互参考；**不能直接复制为 Flutter 代码**。
- 原项目若为 Flutter Web / PWA，请让 Copilot 将 JSX 转换为 Flutter Widget，保留原项目路由、状态管理、接口与权限校验。不要把演示数据或模拟提交当作真实业务实现。

## 给 Copilot 的接入要求

只移植 UI，不重写现有业务。页面字段和功能以原《Skneo 界面设计任务书》为准。

1. 保留首页 / 私信 / 发布 / 通知 / 我的顺序。发布是动作，不是选中 Tab。
2. 首页仅 sk社区 / 约约约；地区与活动类型筛选仅在约约约中显示。
3. 昵称旁的地区、雪场属于作者个人资料，不是帖子位置。
4. 活动类型：约滑 / 约拍 / 约饭 / 约装备。状态：招募中 / 已满员 / 已结束 / 已取消。
5. 作者拥有编辑与删除，所有人均可举报。内容治理入口只对管理员显示。
6. 不添加分享、关注、搜索、电商、支付或聊天。私信、社区服务、设置保持占位。
7. 使用系统黑体、黑白灰、弱分割线和线性图标。深色跟随系统；360–430 宽自适应，不渲染模拟手机状态栏。
8. 列表下拉刷新；媒体横滑；详情评论回复缩进一层；模态弹层支持关闭与无障碍。

## 页面接入

`App` 导出 `SkneoUIProps`，可通过代码单独渲染文档中的任一页面；不需要在产品里加入页面选择器。

```tsx
<App />
<App initialPage="帖子详情" authorView />
<App initialPage="活动详情" activityId={12} />
<App initialPage="活动详情" registrationState="已截止" />
<App initialPage="我的" initialState="未登录" />
<App initialPage="我的" isAdmin />
<App initialPage="内容治理中心" isAdmin />
<App initialPage="登录" appearance="dark" />
```

`initialPage` 支持：首页、sk社区列表、约约约列表、帖子详情、活动详情、发布入口、活动类型选择、发布 / 编辑页、私信占位、通知、我的、我的帖子、我的评论、我的收藏、我的活动、编辑资料、登录、注册、图片查看、视频播放、内容治理中心，以及任务书中的作者主页、社区服务、关于 Snow Fish、设置。

`initialState`：正常 / 加载中 / 加载失败 / 空数据 / 未登录 / 提交中 / 操作成功 / 操作失败。

`registrationState`：可报名 / 已满 / 已截止 / 已开始 / 已结束 / 我是发起人。

`appearance`：light / dark / system。默认跟随系统。

模拟数据、点赞收藏、报名、验证码倒计时与提交延时仅用于 UI 交互。没有邮件、认证、上传或数据库服务；媒体选择仅预览本地文件。视频页保留播放器布局，真实视频地址由项目接口提供。请用原项目数据及回调替换这些部分；权限必须由原项目验证，不能依赖 UI 参数。
